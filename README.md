This is the diary about me starting learning languages, as the adults (25m),
trying to self study Spanish as my 3rd language.

Note that before that I never self study language from scratch like this. Before that I can only speak English and Thai (Thai is my native language).

The reason I decide to learn new language is because I want to make calligraphy in multiple languages for this project ( https://github.com/Turingraph/Sunset-at-04-42pm )

The reason I choose Spanish is because I believe it is 2nd most common spoken language with Latin alphabets, and in the future I want to comparing Indo European languages with Kra–Dai languages.

Also I might learn Japanese as 4th language (because I like Jpop and anime) and Arabic as 5th language (because I like Islamic calligraphy and Islamic art), and I'm always curious what would happened to my personal experience with grapheme color synesthesia if I study new writing system.
